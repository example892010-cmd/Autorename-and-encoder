ANIFLIX Auto Rename & Encoder Bot — reference-based repair build

Main cause addressed:
- The previous repair used a custom plugin-registration loop that filtered decorated callbacks by their Python __module__ value. Pyrogram can wrap decorated callbacks, so that filter can skip real command and media handlers while fallback /start and /ping replies still work.
- Restored Pyrogram's native plugin discovery, matching the working pattern in the uploaded ENCODING-BOT reference: plugins={"root": "plugins"}.
- Removed fallback handlers that could hide a plugin-loading failure. Startup now logs handler counts so an incomplete load is visible.

Other fixes retained:
- /help, /tutorial, and /about have dedicated handlers.
- Start-menu callback filters are restricted so they do not consume force-subscription or metadata callbacks.
- The help menu's Tutorial/About buttons now have matching callback handlers.
- Fixed the metadata FFmpeg argument iteration bug in file_rename.py.
- Hardened missing file names and sanitized output filenames.
- Preserved the existing automatic multi-resolution encoding strategy: incoming video uploads are encoded at configured resolutions and each result is uploaded as it completes. Other supported files continue to the rename handler.
- Preserved branding, database schema, caption, thumbnail, metadata, and force-subscription features.

Render environment variables:
- Required: API_ID, API_HASH, BOT_TOKEN, DB_URL.
- DB_NAME defaults to autorename.
- ADMIN should contain your Telegram user ID(s), separated by commas.
- FORCE_SUB_CHANNELS is optional and should contain channel usernames separated by commas.
- LOG_CHANNEL is optional; set it to 0/empty if not using a log channel.
- Keep credentials private; do not put BOT_TOKEN or DB_URL in source code.

Deployment:
1. Extract this ZIP and replace the repository files with its contents (do not upload the ZIP as a single file).
2. Preserve the actual environment variables already set in Render.
3. Redeploy and check the startup log line "Registered Pyrogram handler counts by group". The count should include many handlers, not just a few.
4. Test /start, /help, /tutorial, /about, /ping, /autorename, then send a small video/document.

Verification boundary:
- Python syntax parsing, required handler markers, native plugin-loader configuration, and ZIP integrity were checked before packaging.
- This environment cannot log into the user's live Telegram bot, Render service, or MongoDB, so live Telegram/database/FFmpeg behavior cannot honestly be certified here. If the issue persists, the Render startup logs around plugin loading and handler counts will identify the next concrete failure. Never share BOT_TOKEN or DB_URL in logs/screenshots.
