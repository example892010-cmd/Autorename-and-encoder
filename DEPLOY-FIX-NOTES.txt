ANIFLIX Auto Rename & Encoder Bot — full plugin-loading fix

Important fixes:
- Plugin filenames use valid Python module names.
- Plugin modules are listed explicitly in the Pyrogram plugin configuration.
- A missing DB_URL no longer prevents all database-dependent plugin modules from importing; /help and /tutorial can still load.
- Database-dependent commands show a clear message if DB_URL is missing.
- Logs include the registered handler counts by group.
- Removed Python bytecode caches from the ZIP.

Render requirements:
- Set API_ID, API_HASH, BOT_TOKEN, ADMIN, and DB_URL.
- DB_NAME should be autorename (unless your database is named differently).
- Set FORCE_SUB_CHANNELS only if you want force-subscription enabled.
- LOG_CHANNEL is optional; leave it at 0 if not using a log channel.
- Never share BOT_TOKEN or DB_URL publicly.

Deploy:
1. Replace the repository files with the contents of this ZIP (do not upload the ZIP as a single file).
2. Keep the actual values for your existing Telegram and MongoDB environment variables.
3. Deploy and check logs for 'Registered handler counts by group'.
4. Test /start, /help, /tutorial, /about, /ping, and /autorename.

Validation:
- Python syntax compilation is run before packaging.
- This archive cannot be verified against your live Telegram token or MongoDB cluster here. A valid DB_URL and Render deployment are still required for saved settings, renaming, thumbnails, captions, metadata, and encoding.
